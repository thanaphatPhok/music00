# 🎵 Discord Music Bot By VeloxGG

บอทเปิดเพลง Discord ใช้งานง่ายดายผ่าน GUI มาพร้อมระบบติดตั้งและเข้าใช้งานอัตโนมัติ (Auto-Installer) สำหรับผู้ใช้งานบนระบบปฏิบัติการ Windows!

## ✨ ฟีเจอร์หลัก

- **🕹 ใช้งานผ่าน GUI:** มีหน้าต่างโปรแกรมสำหรับกรอก Token และสั่งเปิด/ปิดบอท โดยไม่ต้องยุ่งกับ Terminal
- **💾 จดจำ Token อัตโนมัติ:** กรอกเพียงครั้งแรก ระบบจะจัดการบันทึก (Save) Token ของคุณไว้ใช้สำหรับการเปิดบอทในครั้งถัดไป
- **🚀 Auto Installer & Updater:**
  - **ระบบตรวจสอบ Python:** สคริปต์ `start.bat` จะตรวจสอบว่าในเครื่องมี Python หรือไม่ หากไม่มี ระบบจะทำการดาวน์โหลดและติดตั้งให้**อัตโนมัติ**
  - **ระบบ Virtual Environment:** สคริปต์สร้างการจำลองเซิร์ฟเวอร์ (`venv`) ขึ้นมาแยก ไม่รบกวนการทำงานของโปรแกรมอื่นๆ ภายในเครื่อง
  - **ติดตั้ง Library:** สคริปต์จัดการอัปเดตและติดตั้งไลบรารี (`requirement_lib.txt`) ที่จำเป็นต้องใช้ให้ครบถ้วนในทีเดียว
- **🎼 ฟังก์ชันบอท:** รองรับคำสั่งเชิญบอทเข้าห้อง, เล่นเพลงผ่าน YouTube (และลิงก์อื่นๆ), หยุดเพลง, ข้ามเพลง, และดูคิวเพลงได้
- **🏠 ห้องขอเพลงอัตโนมัติ (`/setup`):** สั่งครั้งเดียว บอทจะสร้างห้องขอเพลงให้ พิมพ์ **ชื่อเพลงตรงๆ** ในห้องนั้นได้เลย ไม่ต้องพิมพ์คำสั่งหรือวางลิงก์ก็เล่นได้
- **🎛 แผงควบคุมพร้อมปุ่มกด:** มีปุ่ม พัก/เล่นต่อ, ข้ามเพลง, หยุดทั้งหมด, **🔀 สุ่มเพลง** และแสดง **คิวเพลงปัจจุบันแบบสด** พร้อมรูปปกเพลง อัปเดตอัตโนมัติทุกครั้งที่มีการเปลี่ยนเพลง
- **🔀 สุ่มเพลงอัตโนมัติ:** กดปุ่มเดียว บอทจะสุ่มจำนวน 1-20 เพลงจากหลากหลายแนวเพลง แล้วต่อเข้าคิวให้อัตโนมัติทันที
- **☁️ รันบน Railway ได้ 24 ชั่วโมง:** มีไฟล์พร้อม deploy ขึ้น Railway ให้บอทออนไลน์ตลอดเวลาโดยไม่ต้องเปิดเครื่องคอมทิ้งไว้

## 💬 คำสั่งของบอทที่ใช้งานได้บน Discord (Bot Commands)

### 🏠 วิธีใช้แบบง่ายที่สุด: ห้องขอเพลงอัตโนมัติ
1. พิมพ์ **`/setup`** ในเซิร์ฟเวอร์ (ต้องมีสิทธิ์ Manage Server) — บอทจะสร้างห้อง (หรือใช้ห้องเดิมที่เคยตั้งไว้) พร้อมแผงควบคุมเพลงแบบมีปุ่มกด
2. เข้าห้องเสียงในดิสคอร์ด แล้ว **พิมพ์ชื่อเพลงลงในห้องนั้นตรงๆ** เช่น `เพราะเธอเป็นเช่นนั้น` หรือจะวางลิงก์ YouTube ก็ได้ — ไม่ต้องพิมพ์ `!play` หรือคำสั่งใดๆ เลย
3. ใช้ปุ่ม **⏯️ พัก/เล่นต่อ**, **⏭️ ข้ามเพลง**, **⏹️ หยุดทั้งหมด**, **🔀 สุ่มเพลง** ที่แผงควบคุมได้เลย และคิวเพลง/เพลงที่กำลังเล่นจะอัปเดตให้อัตโนมัติ
   - กดปุ่ม **🔀 สุ่มเพลง** เพื่อให้บอทสุ่มเพลงมาต่อคิวให้อัตโนมัติ 1-20 เพลง (สุ่มจำนวนเองทุกครั้งที่กด) โดยต้องอยู่ในห้องเสียงก่อนถึงจะกดได้

### ⌨️ คำสั่งแบบ Prefix (`!`) แบบเดิม
- `!play <ชื่อเพลง / ลิงก์>` - เชิญบอทเข้าห้องเสียงและทำการสั่งเล่นเพลง (หรือเพิ่มลงคิวหากกำลังเล่นอยู่)
- `!skip` - ข้ามเพลงที่กำลังเล่นปัจจุบัน ไปยังเพลงถัดไปในคิว
- `!stop` - ยกเลิกคิวทั้งหมด และสั่งให้บอทออกจากห้องเสียง
- `!queue` - เช็ครายการคิวเพลงที่คุณและคนอื่นๆ สั่งเอาไว้ทั้งหมด
- `!random` - สุ่มเพลง 1-20 เพลง แล้วต่อเข้าคิวให้อัตโนมัติ (เหมือนกดปุ่ม 🔀 สุ่มเพลง)

## ☁️ วิธี Deploy ขึ้น Railway ให้บอทรัน 24 ชั่วโมง

ไม่ต้องเปิดคอมทิ้งไว้! อัปโหลดโค้ดขึ้น [Railway](https://railway.app) แล้วให้บอททำงานตลอดเวลาแทน

1. **Push โค้ดขึ้น GitHub:** สร้าง Repository แล้วอัปโหลดไฟล์ทั้งหมดในโปรเจกต์นี้ขึ้นไป (รวมไฟล์ `railway_bot.py`, `requirements.txt`, `nixpacks.toml`, `railway.json` ที่เพิ่มมาใหม่)
2. **สร้างโปรเจกต์ใน Railway:** ไปที่ [railway.app](https://railway.app) → New Project → Deploy from GitHub repo → เลือก Repository ของคุณ
3. **ตั้งค่า Environment Variable:** ไปที่แท็บ **Variables** ของโปรเจกต์ แล้วเพิ่มตัวแปรชื่อ `DISCORD_TOKEN` ใส่ค่าเป็น Bot Token ของคุณ (**ห้ามใส่ Token ลงในโค้ดหรือ GitHub โดยตรง**)
4. **Deploy:** Railway จะติดตั้ง Python, ffmpeg (ผ่าน `nixpacks.toml`) และไลบรารีใน `requirements.txt` ให้อัตโนมัติ แล้วรันคำสั่ง `python railway_bot.py` ให้เอง
5. **เช็คสถานะ:** ดู Log ในแท็บ **Deployments** ถ้าเห็นข้อความ `✅ บอทออนไลน์แล้ว!` แปลว่าสำเร็จ บอทจะออนไลน์ตลอด 24 ชั่วโมงตราบใดที่โปรเจกต์ยัง Deploy อยู่

> **หมายเหตุ:**
> - ไฟล์ `railway_bot.py` คือไฟล์สำหรับรันบน Railway (ไม่มีหน้าต่าง GUI) ส่วน `bot.py` ยังใช้สำหรับรันบนเครื่อง Windows ผ่าน `start.bat` เหมือนเดิม ทั้งสองไฟล์ใช้ตรรกะเดียวกันจาก `musicbot_core.py`
> - ถ้าบอทหลุดหรือแครช ระบบจะพยายามเชื่อมต่อใหม่อัตโนมัติทุก 10 วินาที
> - การตั้งค่าห้องขอเพลง (`/setup`) จะถูกเก็บไว้ในไฟล์ `guild_configs.json` — บน Railway ไฟล์นี้จะยังอยู่ตราบใดที่ไม่มีการ Redeploy ใหม่ทั้งหมด ถ้าต้องการให้เก็บถาวรแนะนำให้แนบ [Railway Volume](https://docs.railway.app/reference/volumes) เข้ากับ path ของโปรเจกต์
> - Railway คิดค่าใช้จ่ายตามการใช้งานจริง (ทรัพยากร CPU/RAM ต่อชั่วโมง) ควรตรวจสอบราคาปัจจุบันที่เว็บไซต์ Railway ก่อนใช้งานจริง

## 🍪 แก้ปัญหา YouTube บล็อกว่าเป็นบอท ("Sign in to confirm you're not a bot")

ปัญหานี้พบบ่อยมากเมื่อรันบอทบนโฮสต์คลาวด์ (เช่น Railway) เพราะ YouTube สงสัยว่า IP ของเซิร์ฟเวอร์เป็นบอท วิธีแก้คือใส่ **cookies** จากบัญชี YouTube จริงให้ yt-dlp ใช้ยืนยันตัวตน

> ⚠️ แนะนำให้ใช้ **บัญชี YouTube สำรอง** ที่ไม่ใช่บัญชีหลักของคุณ เพื่อความปลอดภัย

### ขั้นตอนเอา cookies มาใช้

1. **ติดตั้งส่วนเสริมเบราว์เซอร์** ชื่อ [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) (มีทั้ง Chrome และ Firefox)
2. **ล็อกอินเข้า YouTube** ด้วยบัญชีที่จะใช้ แล้วเปิดหน้า youtube.com ทิ้งไว้ (ลองเล่นวิดีโอสักคลิปให้แน่ใจว่าบัญชีไม่ได้โดนให้ยืนยันตัวตนเพิ่มเติม)
3. กดไอคอนส่วนเสริม แล้วกด **Export** เพื่อดาวน์โหลดไฟล์ `cookies.txt`
4. นำไฟล์ `cookies.txt` ไปใช้ตามวิธีที่ตรงกับการรันบอทของคุณ:

   **ถ้ารันบน Railway (แนะนำ — วิธี Base64 กันปัญหาไฟล์เพี้ยน):**
   - เปิด Terminal/PowerShell แล้วแปลงไฟล์เป็น Base64:
     - Windows (PowerShell): `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cookies.txt")) | Set-Clipboard`  (คำสั่งนี้จะคัดลอกผลลัพธ์ใส่ clipboard ให้เลย)
     - Mac/Linux: `base64 -w0 cookies.txt | pbcopy` (Mac) หรือ `base64 -w0 cookies.txt` แล้วคัดลอกผลลัพธ์เอง (Linux)
   - ไปที่แท็บ **Variables** ในโปรเจกต์ Railway → New Variable → ตั้งชื่อ **`YTDLP_COOKIES_B64`** → วางค่า Base64 ที่คัดลอกมา → Save
   - บอทจะถอดรหัสและสร้างไฟล์ cookies ให้เองอัตโนมัติตอนเริ่มทำงาน (ปลอดภัยกว่าการวางข้อความตรงๆ เพราะไม่มีปัญหา tab ถูกแปลงเป็น space)
   - *(ถ้าไม่สะดวกแปลง Base64 ก็ยังใช้ตัวแปร `YTDLP_COOKIES` แบบวางข้อความตรงๆ ได้ แต่มีโอกาสเพี้ยนมากกว่า)*

   **ถ้ารันบนเครื่อง Windows ผ่าน `start.bat`:**
   - วางไฟล์ `cookies.txt` ไว้ในโฟลเดอร์เดียวกับ `bot.py` ได้เลย บอทจะตรวจเจอและใช้งานให้อัตโนมัติ

5. รีสตาร์ทบอท แล้วลองสั่งเล่นเพลงใหม่อีกครั้ง

### ถ้าตั้งค่าแล้วยังเจอ error เดิม ให้เช็คตามนี้

1. **ดู Log ตอนบอทเริ่มทำงาน** (แท็บ Deployments → View Logs บน Railway) ต้องเห็นบรรทัด `[Cookies] ✅ โหลด cookies จาก ... แล้ว` ถ้าเห็น `⚠️` แปลว่าไฟล์ cookies เพี้ยนหรือหาไม่เจอ ให้ทำตามคำแนะนำในข้อความนั้น
2. **cookies หมดอายุ** — เกิดขึ้นได้เรื่อยๆ โดยเฉพาะถ้าออกจากระบบบัญชีนั้นในเบราว์เซอร์ ให้ export ใหม่แล้วอัปเดตค่าตัวแปรอีกครั้ง
3. **ยังใช้วิธีวางข้อความตรงๆ (`YTDLP_COOKIES`) อยู่** — ให้เปลี่ยนไปใช้วิธี Base64 (`YTDLP_COOKIES_B64`) ด้านบนแทน เพราะเป็นสาเหตุอันดับ 1 ที่ทำให้ "ตั้งค่าแล้วยังไม่หาย"
4. **redeploy ให้เรียบร้อย** — หลังเพิ่ม/แก้ Variable ใน Railway ต้องรอให้ระบบ deploy รอบใหม่เสร็จก่อน (เช็คสถานะที่แท็บ Deployments ว่าเป็นรอบล่าสุดจริง)
5. **อัปเดต yt-dlp เป็นเวอร์ชันล่าสุดเสมอ** เพราะ YouTube ปรับระบบตรวจจับบอทบ่อยมาก — ไฟล์ `requirements.txt` ตั้งไว้ให้ดึงเวอร์ชันใหม่แล้ว แต่ถ้า Railway cache เวอร์ชันเก่าไว้ ให้ลองกด Redeploy แบบ "Clear build cache" ใน Railway
6. **ถ้ายังไม่หายอีก ให้ลองใช้ Proxy** — ตั้งตัวแปร `YTDLP_PROXY` เป็น URL ของ residential/mobile proxy เช่น `http://user:pass@host:port` (บาง IP ของ Railway อาจโดน YouTube แบนระดับ IP ไปแล้วโดยไม่เกี่ยวกับ cookies เลย ต้องเปลี่ยนเส้นทางออกอินเทอร์เน็ต)
7. บอทได้ตั้งค่าให้ yt-dlp ลองสวมรอยเป็นแอป YouTube บนแอนดรอยด์ก่อนแล้ว (ซึ่งมักโดนบล็อกน้อยกว่า) แต่ถ้า YouTube เปลี่ยนวิธีตรวจจับใหม่ วิธีนี้ก็อาจต้องอัปเดตตามในอนาคต

> **ห้าม commit ไฟล์ `cookies.txt` หรือ `config.json` ขึ้น GitHub เด็ดขาด** (มีการตั้งค่า `.gitignore` กันไว้ให้แล้ว)

## 👨‍💻 สำหรับนักพัฒนา (Developer Note)

- **ทำไมถึงไม่มี `.exe`?** : เพื่อความเบาและป้องกันระบบแอนตี้ไวรัส (False Positive) ของ Windows การใช้โครงสร้าง `สตริปต์.bat` คู่กับ `venv` ถือว่าเป็นวิธีที่เบา เล็ก เข้าใจง่ายที่สุด และยังช่วยให้สามารถแก้ไข Source code ได้ตลอดเวลาโดยไม่ต้องนั่ง Compile ใหม่
- **ไฟล์ที่ห้ามหลุดสู่ Public:** ระบบจะสร้างไฟล์ `config.json` ให้คุณเอง ซึ่งเป็นไฟล์ที่เก็บ Bot Token ของคุณไว้ **ห้ามเปิดเผยไฟล์นี้ให้ใครเด็ดขาด** (ซึ่งมีการตั้งค่า `.gitignore` เผื่อไว้ให้แล้ว)
